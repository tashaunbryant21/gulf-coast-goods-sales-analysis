# Gulf Coast Goods – Sales Performance Analysis & Dashboard

End-to-end business analytics project analyzing sales performance for a multi-location retail company operating in Southwest Florida (Fort Myers, North Port, and Naples).

## Tools Used
- **SQL (SQLite)** – Data cleaning and transformation
- **Microsoft Excel** – Exploratory analysis with PivotTables and XLOOKUP
- **Power BI** – Interactive dashboard and data visualization

## Project Overview
This project follows the full analytics workflow:
1. Data cleaning of messy transactional data
2. Exploratory analysis in Excel
3. Insight generation and business recommendations
4. Interactive Power BI dashboard

## Key Insights
- **Student Essentials** was the highest-revenue category (~$22.3K)
- **Fort Myers** (flagship store) significantly outperformed other locations
- **In-store sales** generated the majority of revenue compared to online
- Top products: Phone Case, Laptop Sleeve, and USB Hub

## Recommendations
- Expand the Student Essentials product line, especially around back-to-school periods
- Use the Fort Myers flagship as a test location for new products
- Focus on growing the online channel through targeted promotions on top products
- Investigate underperformance at the Naples location
